# ChessFunny

Σκάκι εναντίον AI, στο μπλε στυλ των εφαρμογών Funny.

- Νόμιμες κινήσεις, σαχ/ματ, ροκέ, en passant, προαγωγή, πατ, κανόνας 50 κινήσεων, απλές ισοπαλίες υλικού και τριπλή επανάληψη.
- Εύκολο / Κανονικό / Δύσκολο AI, αναίρεση και υπόδειξη.
- Αποθήκευση παρτίδας και σκορ στο localStorage, χωρίς Supabase, χωρίς λογαριασμό.
- Προσαρμοζόμενη διάταξη κινητού/υπολογιστή. Τα λευκά ανήκουν στον άνθρωπο.

Άνοιγμα μέσω [Applications](https://seemsfunny21.github.io/applications/?app=chessfunny).

Σημείωση: η λειτουργία AI είναι ελαφριά και το παιχνίδι δεν χρησιμοποιεί χρονομέτρηση αγωνιστικού επιπέδου.
